# Archade classroom integration

The original SketchUp source was used locally to create the game-ready environment.

The repository contains only the adapted runtime model and its collision data:
- public/assets/environment/archade/classroom.glb
- public/assets/environment/archade/collision.json

The Archade Free Licence permits use and adaptation within a project, but not redistribution of the source as a standalone file or repackaged asset library. The editable `.skp` source is therefore kept outside this repository.
