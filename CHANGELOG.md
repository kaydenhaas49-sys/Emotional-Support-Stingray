# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-01-16

### Added
- Initial release of First Person Starter Kit
- First-person controller with WASD movement
- Pointer Lock mouse control with configurable sensitivity
- Sprint functionality with Shift key
- Dynamic lighting system with time-of-day presets
- Skybox manager with multiple skybox options
- Debug GUI with lil-gui
- Responsive canvas that adapts to window resizing
- 3D model loading support (GLTF/GLB)
- Social media integration in UI
- Ko-fi support button
- Comprehensive documentation
- MIT License

### Features
- Ground plane with grid reference
- Directional light with soft shadows
- Fog for depth cues
- Multiple lighting presets (Balanced, Morning, Noon, Sunset, Night)
- Settings GUI for runtime tweaking
- Instructions overlay
- Debug console with helpful information
